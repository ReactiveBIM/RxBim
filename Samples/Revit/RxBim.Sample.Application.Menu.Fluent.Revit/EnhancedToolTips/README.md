# Проверка подсказок Revit

В этом примере сравниваются штатные подсказки Revit и интерактивные карточки Markdown в отдельном WPF Popup. Пример использует общий механизм RxBim: расширенное содержимое задаётся свойством `EnhancedToolTip`, штатное — свойствами `ToolTip` и `Description`.

Соберите `RxBim.Sample.Application.Menu.Fluent.Revit.csproj`, используя настройки нужной версии Revit в репозитории. Подключите приложение через существующий манифест примера и откройте **RxBim > Enhanced tooltips**. Расширенные подсказки подключаются автоматически при построении ленты; отдельных сервисов показа внутри примера больше нет.

| Кнопка | Содержимое и способ показа |
| --- | --- |
| Native | Штатная подсказка Revit без изменений: краткий текст, подробное описание, версия и контекстная справка |
| Popup with native | Та же карточка в отдельном WPF Popup; исходная штатная подсказка сохраняется, но отключается для этой кнопки |
| Картинка и таблица | Общий пример BimTeam.Markdig.Wpf: встроенный PNG, таблица с выравниванием и HTTP(S)-ссылка; есть также в Tooltip menu |
| From attribute | Подсказка команды Cmd3 из `RxBimCommandAttribute.EnhancedToolTip` |
| Popup only | Отдельный Popup без заданных `ToolTip` и `Description` |
| Stacked buttons / Tooltip menu | Сравнение штатной подсказки и Popup на кнопках в стеке и пунктах меню |

У тестовой команды намеренно нет `RxBimCommandAttribute`, поэтому вариант Popup only не может унаследовать штатную подсказку из метаданных команды. Все тестовые кнопки выполняют одну и ту же команду, которая только показывает сообщение с подтверждением.

## Проверка картинки и таблицы в обоих хостах

В Revit откройте **RxBim > Enhanced tooltips > Картинка и таблица**, в AutoCAD —
**RxBim > Enhanced tooltips > Картинка и таблица**. Такой же пункт добавлен в
**Tooltip menu** обоих примеров.

1. Наведите курсор и дождитесь Popup: должна появиться картинка «RxBim | Markdown».
2. Проверьте таблицу: три столбца, заголовки, границы, выравнивание слева / по центру / справа,
   жирный текст и код внутри ячеек.
3. Картинка должна помещаться по ширине карточки. Она встроена в DLL и не требует интернета
   или отдельного PNG рядом с установленным плагином.
4. Прокрутите карточку до ссылки документации и справки. Проверьте клик, F1 и закрытие по Escape.
5. Повторите проверку для пункта меню, перемещая курсор из списка внутрь Popup.

Оба проекта используют один [исходник Markdown](../../../Shared/EnhancedToolTipSampleContent.cs)
и одно [изображение](../../../Shared/tooltip-renderer.png), подключённые через csproj.
Существующие команды переиспользуются; показ подсказки и переход по ссылке не должны запускать команду.

## Ручная проверка в Revit

1. Наведите курсор на **Native**, дождитесь подробного описания и нажмите F1. Повторите проверку для кнопки Native в стеке и пункта Native в меню.
2. Сравните **Native** и **Popup with native**. Проверьте форматирование Markdown, прокрутку, переход курсора с кнопки внутрь карточки и обе гиперссылки. Переход по ссылке не должен запускать команду.
3. Убедитесь, что **Popup only** показывает ту же карточку, хотя текст штатной подсказки не задан.
4. Нажмите F1, пока карточка видна. Сайт справки RxBim должен открыться один раз в браузере по умолчанию, без окна справки Revit. Нажмите F1 вне карточки и убедитесь, что работает обычная справка Revit.
5. Уведите курсор с кнопки и карточки, нажмите Escape, щёлкните снаружи и переключитесь в другое приложение. Также проверьте быстрый клик или Escape в течение начальной задержки показа 400 мс: подсказка не должна появляться с опозданием поверх диалога команды.
6. Повторите проверку в **Tooltip menu**. Переместите курсор внутрь карточки, перейдите по ссылке, закройте меню и переключитесь между его пунктами. При переходе внутрь Popup список может закрыться, освобождая захват мыши; карточка при этом должна остаться открытой и принимать клики по ссылкам. Пункты со штатными подсказками должны сохранять своё поведение.
7. Переключите тему Revit, измените масштаб экрана или переместите окно на другой монитор. Добавьте тестовую кнопку на панель быстрого доступа. Отметьте, какое поведение сохраняет её копия: штатное или расширенное. Поддержка копий кнопок на панели быстрого доступа в варианте Popup пока не реализована.
8. Закройте Revit. Контейнер приложения освобождает тестовые сервисы, восстанавливает исходное состояние подсказок и отключает глобальные обработчики ввода.

Вариант Custom content исключён после проверки в Revit: гиперссылки внутри штатной подсказки не принимают клики. Варианты **Popup with native** и **Popup** используют один механизм, но расположены на разных типах кнопок. У них задана штатная подсказка, которая сохраняется, но не показывается, пока работает Popup. У **Popup only** штатные `ToolTip` и `Description` не заданы.

Для F1 используется `WH_GETMESSAGE` только на UI-потоке Revit: для обработанного F1 поглощаются и сообщение клавиши, и отдельный запрос штатной справки `WM_KEYF1` (`0x4D`). Перехват устанавливается при регистрации расширенных подсказок и снимается при очистке или освобождении сервиса. При видимой карточке ссылка справки ставится в очередь Dispatcher и открывается через общий `LinkLauncher` после выхода из перехвата F1 (`Process.Start` с `UseShellExecute = true`); без карточки сохраняется штатная обработка Revit. Удержание F1 не должно открывать повторную справку. Положение указателя проверяется в экранных координатах, чтобы захват мыши выпадающим меню не мешал переходу внутрь карточки. Фактическую маршрутизацию сообщений и поведение после закрытия меню необходимо проверить в Revit.
